MYSTERY WHEEL

Files:
- index.html
- style.css
- script.js

Run:
1. Put these files in a folder.
2. Open index.html directly, or serve the folder with your Express app.
3. Click SPIN THE WHEEL.

Features:
- 24 unique missions
- No repeats until all missions are cleared
- Animated spinning wheel
- Task reveal modal
- Completion tracking
- Score + streak
- Recent mission history
- LocalStorage persistence
- Confetti + Web Audio effects
- Keyboard support: Space = spin, Esc = close
- Responsive mobile layout
